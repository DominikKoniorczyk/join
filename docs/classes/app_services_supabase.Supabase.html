    getDataFromTable

    • getDataFromTable(tableName: string, selector?: string): Promise<any>

      Fetches data from a specified Supabase table.

      This method queries the provided table using the Supabase client and returns the selected columns. If no selector is provided, all columns (*) will be retrieved.

      Parameters

      • tableName: string

        The name of the database table to query.

      • Optionalselector: string = '*'

        The column selector string (e.g. '', 'id,name'). Defaults to '' which selects all columns.

      Returns Promise<any>

      A promise that resolves to:

      • An array of records if the query is successful (empty array if no data is found).
      • null if an error occurs during the query.

      Example

      const users = await getDataFromTable('users');

      Example

      const userNames = await getDataFromTable('users', 'id, name');

    • uploadJSONToTable(tableName: string, jsonData: any): Promise<null>

      Uploads JSON data to a specified Supabase table.

      This method inserts the provided JSON object or array of objects into the given table using the Supabase client.

      Parameters

      • tableName: string

        The name of the database table where the data should be inserted.

      • jsonData: any

        The JSON object or array of objects to insert into the table.

      Returns Promise<null>

      A promise that resolves with the inserted data returned by Supabase.

      Async

      Throws

      Throws an error if the insert operation fails.

      Example

      await uploadJSONToTable('users', {
        name: 'John Doe',
        email: 'john@example.com'
      });

      Example

      await uploadJSONToTable('users', [
        { name: 'John Doe', email: 'john@example.com' },
        { name: 'Jane Doe', email: 'jane@example.com' }
